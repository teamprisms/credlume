# Credit Health Pro 3.0

A browser-based prototype for a personal financial/credit-health dashboard.

## Included
- Credit health dashboard
- Credit score breakdown
- Credit card management
- Loans & EMI tracking
- Debt strategy
- Personal wallet
- Spending/expense tracking
- What-if credit simulator
- Financial calendar
- AI Copilot interface
- Action plan
- RBI safety section
- Profile & credentials
- Multi-language UI

## Run locally

Open `index.html` in a modern browser.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and this `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub Pages will publish the prototype.

## Important
This is currently a front-end/demo prototype. Authentication, financial data, AI responses, banking integrations, and persistent storage should be connected to a secure backend before production use.

The original prototype uses CDN-hosted Tailwind CSS, Font Awesome, and Google Fonts, so an internet connection is useful when loading it.
